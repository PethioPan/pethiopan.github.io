telebirr Integration

Complete

83 tests, no network
Zero runtime deps

A direct client for Ethio Telecom's payment gateway, so an Ethiopian site can take money without paying an aggregator per transaction.

Every local option routes through a middleman that takes a cut of each sale. This talks to the Fabric gateway itself: RSA request signing, token lifecycle, and a diagnostic command that walks TLS, then token, then signature so a failing integration tells you which layer broke. A mock gateway mode runs the entire checkout end to end without live credentials, which matters in a market where credentials take months.
